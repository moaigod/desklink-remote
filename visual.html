A casual local remote access setup for your own devices

Browser remote access

Use your Chromebook to join another browser as a peer over a local room code.

This browser flow is the peer-only path: the host and viewer connect directly through WebRTC, while the local server only relays the signaling handshake.

  • Works from a Chromebook
  • No app install on the viewer
  • Uses WebRTC for screen sharing

How to use it

  1. Run the project locally with the server in this folder.
  2. Open the page on your Chromebook or viewer device.
  3. Enter the room code from the host and click Join.
  4. The remote screen should appear in the browser.
