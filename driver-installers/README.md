DeskLink 1.1.1 includes these **unmodified official downloads** for convenience. They are optional, host-only, and are never launched or installed automatically by DeskLink.

Read [GAME-DRIVERS.md](../GAME-DRIVERS.md) before installing either one. The downloaded Interception archive contains its own license files. ViGEmBus licensing and release details are available from its official release page.

If a game or anti-cheat disallows either driver, do not use it for that game. DeskLink does not bypass game restrictions.
